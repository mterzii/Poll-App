# PollApp
A simple and interactive polling application where users can vote on choices and instantly see the results in a clean, responsive UI.

## Features
- Create poll questions  
- Add multiple choices  
- Vote instantly  
- Auto-updating results  
- Responsive interface  
- Lightweight vanilla JavaScript
